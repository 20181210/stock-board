多日周期设置

每N个实际交易日合成一根K线，跳过休市日。加密货币每天交易，按UTC分日。5日K线与自然周K线分别计算。周线从周一开始；月线按自然月，3月为季度，12月为年线，均不受下方日期影响。

从此日期当天或之后的第一个交易日开始分组；更早的数据向前倒排。对齐日期应在已加载数据范围内。固定此日期可保持后续分组稳定。

你的免费图表工作台

输入品种代码后按Enter加载。A股还支持输入股票名称搜索，例如“贵州茅台”“平安银行”，从下拉建议中选择。示例：美股 AAPL / NVDA / SPY，A股 600519 / 000001，外汇 EURUSD / USDJPY / XAUUSD，加密 BTCUSDT / ETHUSDT。

点击左侧工具，在图表上依次点击落点即可画线。通道和斐波那契扩展需要三个点，其余通常两个点，水平线一个点。测量尺可拖动或依次点击两点，显示价格差、涨跌幅、K线间隔和自然日数，Alt+R打开，Esc退出。鼠标悬停K线显示相对上一根收盘的涨跌幅。完成后可以选中拖动，Delete删除选中画线，Ctrl+Z撤销最后一笔，Esc退出绘图。

画线按“市场、代码、周期和对齐日期”分别保存。自选和画线存在当前浏览器本地；清除浏览器数据会丢失。行情缓存位于项目data/cache目录。

CSV表头：date,open,high,low,close,volume。date为YYYY-MM-DD，volume可省略；导入按日线处理。数据仅保存在当前页面，画线仍可本地保存。导出CSV是当前合成周期的数据。

免费公开接口可能延迟、限流或停止服务。本工具用于个人图表分析；请查看右下角数据来源和最后行情日期。图表库 KLineCharts 9.8.12，Apache-2.0，许可证见项目public/vendor。

PMA 多重均线

默认按图片2：8、144、169、13启用，338关闭，576和676启用。指标周期按当前图表K线计算。EMA从首个价格递推；SMA/WMA/RMA/ALMA达到周期长度后显示。位移以K线根数计算，超出已有数据的部分暂不绘制。

斐波那契线设置

选择要显示的回撤/扩展比例，并设置每条线的颜色。先在图表中选中一条斐波那契线，再应用设置可同步修改它。
