# 股票看板 · Free Chart

免费的本地看盘工作台，支持美股、外汇、黄金、A股、加密货币日线，支持自定义日/周/月周期、画线和CSV导入。无需注册，无需API Key。需要Python 3.8+和Node.js（用于股票完整历史解码），无需安装pip或npm依赖；图表库已保存在本地，打开页面无需下载CDN资源。

## 启动

Windows双击 `start.cmd`，会在后台启动本地服务并打开 `http://127.0.0.1:8765`。也可以在项目目录运行：

```powershell
python server.py
```

服务仅监听127.0.0.1。默认8765端口，可以用 `python server.py --port 8766` 修改。停止后台服务时，可在任务管理器中结束本项目对应的Python进程。若使用终端启动，Ctrl+C即可停止。

### macOS / Linux

安装Python 3和Node.js后，在项目目录运行：

```bash
python3 server.py
```

浏览器打开 `http://127.0.0.1:8765`，终端按Ctrl+C停止。Windows快捷方式和`.cmd`/`.ps1`/`.vbs`启动脚本仅适用于Windows；核心服务和网页使用跨平台代码，macOS尚未实机验证。自选、画线和设置保存在当前浏览器中，不会随代码仓库迁移到另一台电脑。

## 使用

- 测量尺：点击左侧尺子图标（Alt+R），在主图按住拖动，或依次点击起点、终点。显示价格差、涨跌幅、K线间隔数和自然日数，完成后自动保存，可拖动调整；Esc取消。
- 鼠标移动到或点击任意K线，顶部和图内提示显示该根K线相对上一根收盘价的涨跌幅；自定义多日线按当前合成周期比较，首根没有前值时显示“—”。
- 选择市场，输入代码，按Enter。A股可以直接输入6位代码，也可以输入股票名称（例如“贵州茅台”“平安银行”），从建议列表选择或直接回车匹配第一项；名称搜索来自东方财富公开搜索接口。美股：AAPL、NVDA、TSLA、SPY；外汇：EURUSD、USDJPY；加密：BTCUSDT、ETHUSDT。
- 顶部周期下拉菜单按天、周、月分组，可选择1/2/3/5/10日、1/2/3周、1/3/6/12月。点击“添加自定义周期”可设置1–250日、1–52周或1–120月，自动保存至菜单，×可移除自定义菜单项。当前免费数据基于日线，菜单提供日、周、月及其合成周期。
- 多周从固定的周一（1970-01-05）对齐，每N个自然周合并，补充历史不会改变分组；多月从1970年1月对齐，每N个自然月合并（3月为自然季度、6月为半年、12月为年线）。首尾可能包含未满周期的数据。周/月合成不受“分组对齐日期”影响。
- 多日线按实际交易日顺序合成，不按自然日补空数据。N日线开盘为首日开盘、最高最低为组内极值、收盘为末日收盘，成交量求和。最新一组可能不足N日，页面会提示。周线按周一至周日，月线按自然月计算。
- “周期设置”指定分组对齐日期，默认2025-01-01。从此日期当天或之后的首个交易日开始分组，之前的交易日向前倒排，防止历史窗口滑动导致后续K线全部移动。日期必须在数据范围内；当接口的历史范围不再覆盖该日期，页面会要求重新选择。修改对齐日期会切换到独立的画线集合。
- 左侧支持趋势线、水平线、射线、平行通道、斐波那契回撤/扩展、矩形。选工具后依次点击落点，完成后自动返回选择模式。通道和斐波那契扩展需要三个点。完成后可拖动线条或控制点；Delete删除选中画线，Ctrl+Z删除最后一笔画线，Esc取消正在绘制的图形。斐波设置支持各级别开关、比例、颜色及区域填充。
- 支持PMA多重均线、成交量、MACD、RSI。PMA支持EMA/SMA/WMA/RMA/ALMA、自定义周期与颜色，默认参数为8、144、169、13、338（关闭）、576、676。指标以当前合成K线计算。
- 顶部标签可切换多个已打开品种，支持关闭和添加；显示的是该品种上次加载的价格及当前周期涨跌幅，不是实时推送报价。
- 自选和画线保存于浏览器localStorage。画线按市场、代码、周期、对齐日期隔离。请使用相同的地址和浏览器，清除浏览器数据会丢失这些设置。行情快照保存在 `data/cache`，上游临时失败时会显示缓存并明确提示。
- 右上角相机导出带画线的PNG；右下角导出当前周期CSV。
- CSV表头为 `date,open,high,low,close,volume`，日期格式YYYY-MM-DD；volume可省略，编码UTF-8。导入仅支持原始日线，拒绝重复日期、非有限值和无效OHLC，也拒绝带多日session_count的导出文件，防止重复聚合。导入数据仅保存在当前页面，刷新后需重新导入。

## 数据来源与限制

| 市场 | 免费公开接口 | 说明 |
| --- | --- | --- |
| A股 | 新浪财经历史数据 | 拉取接口全部可用日线，比例前复权；成交量单位为股。名称搜索使用东方财富公开建议接口 |
| 美股 | 新浪财经历史数据 | 拉取接口全部可用日线；拆股复权，不含现金分红、盘前盘后；不同品种历史起始日期不同 |
| 外汇 | 新浪财经 NewForexService | 长期参考日线；无成交量，不同报价商收盘时间和价格可能不同 |
| 黄金 | 新浪国际现货黄金 XAU | XAUUSD参考日线，拉取接口全部可用历史；不是COMEX黄金期货 |
| 加密 | Binance data-api.binance.vision | 分页拉取交易对上线以来的可用日线；UTC 00:00分日；成交量为基础币数量 |

所有数据均来自实际接口，不使用模拟行情。公开接口可能限流、改版、区域不可访问或停止服务，且不是保证实时的授权行情。对外发布或商业分发前需要自行取得相应数据许可。不同市场之间的成交量单位不可直接比较。

缓存5分钟，点击刷新可主动请求上游。默认直连；如果需要代理，先设置环境变量 `MARKET_PROXY=http://127.0.0.1:端口` 再启动服务。

本版本重点是日线和自定义日/周/月图表；不含分钟线、下单、实时推送或云同步。
